# 数据与隐私

## 保存在本地的内容

追番状态、计划、评分、笔记、感想、标签、观看记录和推荐偏好都保存在本机的 SQLite 数据库里，截图原图保存为独立文件。AniMeido 不需要注册账户，不收集使用统计，也不会把个人记录上传到任何服务器。

## 应用会访问的网络地址

| 地址 | 用途 |
| --- | --- |
| `archive.animeido.com`、`bgm-proxy.animeido.com` | 获取番剧资料和图片。前者是 [Bangumi](https://bgm.tv/) 公开数据的镜像，后者转发 Bangumi API |
| `animeido.com`、`dl.animeido.com` | 检查和下载更新 |

这些请求只包含查询所需的作品、人物或搜索关键词，不包含你的个人记录。番剧资料和图片会缓存在本地，网络不可用时可以继续浏览已缓存的内容。

可选的 Player 插件在你播放时会访问对应的视频网站。

## 备份与迁移

| 方式 | 包含内容 | 适用场景 |
| --- | --- | --- |
| 数据库备份 | 完整的本地数据库 | 在同一台电脑上恢复 |
| JSON 导出 | 状态、档案文本、标签、统计和推荐偏好，不含截图 | 查看或处理数据，或在电脑间迁移文字记录 |
| 完整档案包（ZIP） | JSON 内容、截图元数据、截图原图和校验清单 | 换电脑时完整迁移 |
| 年度回顾（HTML） | 当年的统计和精选感想、截图 | 分享和留念，不能当作备份 |

换电脑时请使用完整档案包。

## 以后的变化

- **资料来源迁移**：接入自有资料服务时，记录中的 Bangumi 关联会迁移到新的作品身份。迁移前会提示备份，无法确定对应关系的记录会保留下来等你确认，不会自动删除。
- **跨设备同步**：尚未实现。上线后由你自己决定是否开启；同步服务不可用时，本地照常读写。同步不能代替备份。
- **插件数据**：插件的私有数据和登录凭据不会进入普通备份。
