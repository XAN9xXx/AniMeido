# 数据与隐私

## 保存在本地的内容

追番状态、计划、评分、笔记、感想、标签、观看记录和推荐偏好都保存在本机的 SQLite 数据库里，截图原图保存为独立文件。AniMeido 不需要注册账户，不收集使用统计，也不会把个人记录上传到任何服务器。

## 应用会访问的网络地址

| 地址 | 用途 |
| --- | --- |
| `api.animeido.com:38443`、`img.animeido.com:38443` | 分别获取番剧资料和图片 |
| `animeido.com`、`dl.animeido.com` | 检查和下载更新 |
| `api.github.com`、`raw.githubusercontent.com` | Player 根据你添加的 GitHub 订阅地址，查询源文件版本并下载源文件 |

番剧资料请求只包含查询所需的作品、人物或搜索关键词，不包含你的个人记录。番剧资料和图片会缓存在本地，网络不可用时可以继续浏览已缓存的内容。

可选的 Player 插件在你播放时会访问对应的视频网站。

Player 的源订阅预览会查询 GitHub 提交和文件列表，再下载该次提交中的源文件。这些请求只包含仓库、版本和文件路径，不发送你的追番、评分或观看记录。

预览会在本地保存源文件版本缓存。已安装且未变化的源不重复下载正文。缓存不安装或启停来源；缓存保存失败时，预览仍可使用，下次会重新读取。

## 备份与迁移

| 方式 | 包含内容 | 适用场景 |
| --- | --- | --- |
| 数据库备份 | 完整的本地数据库 | 在同一台电脑上恢复 |
| JSON 导出 | 状态、档案文本、标签、统计和推荐偏好，不含截图 | 查看或处理数据，或在电脑间迁移文字记录 |
| 完整档案包（ZIP） | JSON 内容、截图元数据、截图原图和校验清单 | 换电脑时完整迁移 |
| 年度回顾（HTML） | 当年的统计和精选感想、截图 | 分享和留念，不能当作备份 |

换电脑时请使用完整档案包。

## 资料迁移与以后的变化

- **旧版资料迁移**：应用已使用自有资料服务。升级旧数据库时，应用先备份数据库，再更新作品关联。无法确定对应关系的记录会保留，等你确认。
- **跨设备同步**：尚未实现。上线后由你自己决定是否开启；同步服务不可用时，本地照常读写。同步不能代替备份。
- **插件数据**：插件的私有数据和登录凭据不会进入普通备份。
