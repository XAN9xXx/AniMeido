# AniMeido 3.0.0 · Windows 桌面版

## 从 2.x 升级

1. 完全退出旧版 AniMeido。如果它还在任务栏右侧的托盘里，右键图标，选择「退出」。
2. 运行 AniMeido_setup_3.0.0.exe，按提示安装，然后打开新版。新版会装在新的位置，无需先卸载旧版，也无需手动搬数据库或截图。
3. 如果新版提示「旧版 AniMeido 仍已安装」，点「卸载旧版本」，避免以后误开旧程序。追番状态、个人评分、作品笔记和已关联的截图都会保留。

如果你有旧的追番记录，第一次打开新版时请保持联网。AniMeido 需要查询旧记录对应的是哪一部作品，才能把评分、笔记和截图继续放在正确的作品下。遇到「资料迁移未完成」时，保留原数据，恢复网络后在原窗口点「重试」，不用重新安装。要查看迁移前的备份，可点「打开备份文件夹」。

## 桌面版的变化

- 由于缺少可用播放源，3.0.0 暂停在线播放。旧播放器插件会停用，已有观看记录和播放器设置保留。

3.0.0 起结束对 2.x 的支持。用安装包装好新版后，后续版本可在应用内更新。
