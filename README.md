# AniMeido

AniMeido 是个人动画管理应用，用来整理追番与补番状态、计划、评分、笔记、感想和截图，并提供放送日历、今天页、番剧库、搜索与本地偏好推荐。

## 当前版本

- Windows x64 桌面应用，使用 C#、.NET 8 和 WinUI 3。
- 基础版可独立使用，不需要安装播放器或登录外部账户。
- 在线播放由**可选的 Player 插件**提供，不随基础版默认安装。
- 核心个人记录保存在本地，公共番剧资料目前主要来自 Bangumi。

## 开发方向

正在筹划多源公共资料服务，范围是资料数据库、来源标注、身份映射和图片懒加载缓存，不提供动画或音乐源文件。

未来计划采用 Uno/C# 迁移。

## 本地开发

使用 Windows x64 和支持 .NET 8／WinUI 的开发环境，解决方案入口为：

```powershell
dotnet build AniMeido.slnx
```
